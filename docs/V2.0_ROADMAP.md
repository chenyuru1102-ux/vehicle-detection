# V2.0 research roadmap (proposal only)

1. Inventory source videos, permissions, and personally identifying content; define what may be shared.
2. Freeze a deduplicated dataset and class ontology (`car` versus `vehicle`). Create independent test videos/cameras before model selection.
3. Review labels manually; prevent prelabel tools from overwriting approved labels and record label provenance.
4. Specify controlled CPU/GPU experiment settings: fixed split, seed, image size, batch strategy, confidence, IoU, model family, software versions, and hardware.
5. Train on RTX 5060 after the protocol is frozen; log runs and checkpoints. This document does not report a GPU run.
6. Evaluate precision, recall, mAP50, mAP50–95, false positives by scene, runtime, and memory on the untouched test set.
7. Implement tile coordinate remapping and merge with NMS if small object exploration warrants it; separately design and validate occupancy logic.
